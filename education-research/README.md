# Education research — Bas

Durable record of research done on supporting Bas academically. Kept here because
Claude Code sessions are ephemeral; this is the persistent copy.

## Context

- **Child:** Bas, age 4. Starts Reception at **The Belham Primary School**, Peckham (SE15), Sept 2026.
- **Family location:** Peckham SE15. Dutch-speaking household (Dutch as home language).
- **The decision behind all this:** chose a state place over a ~£30k/yr private school.
  The worry is that a bright child won't be stretched and nobody will systematically notice.
- **Goal:** build an all-round profile strong enough to win a place at one of the best
  schools in the country at **11+** (entry Sept 2033, exams autumn 2032).
- **Interests:** STEM / maths.
- **Budget:** not the binding constraint. **Geography is** — must be reachable from SE15.
